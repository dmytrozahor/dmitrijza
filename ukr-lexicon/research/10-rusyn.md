## 1. rusynsociety.com/rue/

- **What it is.** A WordPress site (Yoast `robots.txt`: `Disallow:` empty, `Sitemap: https://rusynsociety.com/sitemap_index.xml`) with ENG (`/`), RUE (`/rue/`) and RUL (`/rul/`) editions. Its content is political and opinion writing, not a linguistic reference.
- **Self-description** ([/rue/about/](https://rusynsociety.com/rue/about/)) [rend]: «Общество про русинськый розвуй (ОРР) — аналітичный центр, закладеный Старіком Поллоком у октовброви 2020. года.» «Наша місія — помочи розвойови інтеллектуалної, творчої тай політичної карпато-русинської мысли у цілому світови.» Tagline: «Слобода через мышліня, розвуй через діяня». No location is given.
- **Stance.** The site is openly an advocacy outlet, for example «Українізм давно ся провказав єднов из майвеликых екзистенційных угроз» [rend]. Treat its texts as evidence of usage, never as evidence about status.
- **Sections.** `/rue/category/reports/`, `/rue/category/nonfiction/{history,opinion,long-form}/`, `/rue/category/karpato-rusynism/` («Кодекс»), `/rue/archive/`, and the standard at **`/rue/sre-standard/`**.
- **Language materials.** It has no dictionary and no grammar book. It has one orthographic and grammatical standard, **«Універзалный Пудкарпатськый Русинськый Стандарт» (УПРС)**. The preface is signed «Составитиль», dated «У Львові, 2025. года, місяця юлія». Its basis is «Сеся робота бере до увагы головно говоры на території Пудкарпатської Руси» [rend]. Its bibliography cites Kerča/Popovyč 1999 and Lyzanec 2008, among others. Its maxim is «не кывайме тото, што и так фунґує».
- **Licence.** None is given, only «© Общество про русинськый розвуй 2026». Treat everything as all rights reserved: short quotations as citations are fine, bulk ingestion is not.
- **Scrapability.** Pages, `wp-json` and feeds are all blocked for non-browser clients by the Cloudflare challenge, and nothing on the site permits automated collection. Do not scrape it. Cite single pages manually.
- **Which codification does it follow?** Its own (УПРС), which is **Subcarpathian**. It uses the Ukrainian alphabet plus mandatory Ы and optional Ӱ, and Ukrainian-style `-ськ-` (русинськый). It is not the Prešov standard, which writes `-ньск-` and uses ё, ъ. Лонкін confirms that the 2015 grammar and УПРС made Ӱ/Ü optional: «графемы Ӱ, Ü были признаны факультативными в универсальном стандарте [УПРС]».

## 3. Detectable single-form markers

Conventions: rows have the same shape as `dia()`, on axis `rusyn`, and fire only when `!normative(c)`. `V` = variants (L lemko, P presov, N pannonian, S subcarpathian). The weights below are suggestions.

**The ы problem.** Rusyn ы must be kept apart from Russian ы. Russian writes ы, but almost never in these four contexts:

1. after к/г/х/ґ;
2. after ь;
3. together with і/ї/є/ґ in the same word;
4. in a `-ти` infinitive.

Those four contexts are the discriminators. Forms such as `мы, ты, рыба, сын` are spelled the same in Russian and Rusyn and **cannot be decided from the form alone**.

## 5. Modelling recommendation

**Axis.** Add `axis: 'rusyn'` with `label ∈ {lemko, presov, pannonian, subcarpathian, rusyn}`, where `rusyn` means "variant undetermined". Define rows as data, `rue(id, variants[], re, w, srcKey, quote)`, mirroring `dia()`. Add sources `UPRS` (rusynsociety standard), `ENC87`, `ENC162`, `LONKIN`, `MATLOVIC`, `RUEWIKI` to `SRC`. Mark every [rend] quote as `P()` until it has been checked in a browser.

Also add the missing **`ZAK` (закарпатський говір)** dialect code to `DIALECTS`, with ENC um162 as its source. Then the same form gets *two parallel, non-competing* readings: `dialect:ZAK` (the Ukrainian dialectology framing) and `rusyn:subcarpathian` (the codified-standard framing). The status question is left open. The UI shows both labels together with the §0 note.

**Gate.** Rusyn rules fire when `!normative(c)`. Use no year gate, or year ≥ 1850, because the Pannonian rules need Kostelnik 1904/1923 and Dukhnovych-era texts. Sources tagged `lang ∈ {rue, rsk}` (rue.wiki, Rusyn press) get a prior of 0.5 on the axis. Single-form scores combine as in research/05: `1 − Π(1 − wᵢ)`. Shared rows from §3 count toward `rusyn:*` only when at least one Rusyn-specific row (RUE-*, PAN-*) fires, so that every Boyko or Hutsul form does not get labelled Rusyn.

**Veto/gate for ORT-Y and ORT-YI.**

```ts
const RUSYN_STRONG = ['RUE-Y-VELAR','RUE-Y-SOFT','RUE-ADJ-SKYJ','RUE-Y-MIX','RUE-Y-INF','RUE-UE']
// ORT-Y (ы ⇒ russianism_orth):
//   veto if any RUSYN_STRONG fired, or source lang ∈ {rue}, or dialect CARP-Y/ZAK context;
//   if form ∈ {мы, ты, вы, сын, рыба, был…} with no discriminator → label 'ambiguous_y'
//   (russian | rusyn | carpathian dialect), weight 0.2, resolve from document context.
// ORT-YI (ё/ъ): veto when RUE-PRESOV-YO fires or source is Prešov/Lemko
//   (both alphabets contain ъ; Prešov has ё). э remains a russianism signal (no Rusyn alphabet listed has э).
```

Positive Russian evidence that keeps ORT-Y alive:

- ы together with э;
- an `-ть` infinitive with ы (быть);
- `-ский` (not `-ськый`/`-ьскый`);
- a hit in a Russian wordlist with no RUSYN_STRONG row firing.

**Note on research/05.** The existing note «ы також у карпатських говорах (див. CARP-Y)» on ORT-Y is now backed by this gate. Update research/05 §3.2 to reference the gate.
